# common-passwords.txt

Contraseñas comunes que `PasswordPolicy` rechaza (sin distinguir mayúsculas).

- Fuente: SecLists, `Passwords/Common-Credentials/xato-net-10-million-passwords-1000000.txt`
  (https://github.com/danielmiessler/SecLists).
- Licencia: MIT, Copyright (c) 2018 Daniel Miessler.
- Filtrado: solo entradas de 12 caracteres o más (el mínimo de la política), en minúsculas, sin duplicados
  y solo ASCII imprimible. Una por línea.
